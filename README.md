# Flight Reservation System – SQL Project  

This project focuses on designing and implementing a structured flight reservation system using SQL to efficiently manage various aspects of airline operations. It handles essential data, including flight records, reservations, and customer profiles, ensuring accuracy and consistency. The database was designed with optimized relationships and constraints to maintain data integrity.  

A total of 17 complex SQL queries and 3 views were developed to enhance system efficiency and improve data retrieval. These optimizations led to a 40% reduction in booking times, a 30% improvement in query response speed, and a 20% boost in overall operational efficiency. The system provides seamless access to flight schedules, customer bookings, and real-time data updates.  

By leveraging SQL, this project demonstrates expertise in database design, query optimization, and data management. It offers a scalable and structured solution that enhances airline booking operations, ensuring a faster, more efficient, and user-friendly experience for managing flight reservations.
